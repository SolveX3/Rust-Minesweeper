# Rust Minesweeper
While I was teaching myself Rust a while back, I thought it would be a good idea to have some sort of larger project to do to better familiarize myself with the language than by just copying all the code from the textbook. And since minesweeper is a fun game that's easy to understand, I decided to make a version of it that can be played in the command line. And so, here we are!

- Select any of the three standard board sizes (9x9/10, 16x16/40, or 30x16/99) or pick your own custom board
- Board display includes color-coded numbers and a checkerboard pattern for easy counting
- Includes first-click safety, zero chaining, and chording
